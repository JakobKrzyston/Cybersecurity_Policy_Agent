  Slice 10: Golden test set + CI regression suite

  Here's what I'm proposing before writing a line:

  Architecture
  - tests/test_golden.py — a single parametrized test driven by a GOLDEN_CASES
  list (plain Python dicts). Adding a new scenario = adding one dict entry, zero
   test logic changes.
  - Each case specifies: request, session context, blocklist, store pre-seeding,
   retriever chunks, LLM stub decision, and expected action / cited_sections /
  user_message_draft pattern.
  - The LLM is stubbed (same pattern as test_pipeline.py). All other components
  — Trust Gate, Citation Grounding, Tool Executor, Rate Limit Store — run real
  code.
