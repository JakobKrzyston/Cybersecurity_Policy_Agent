  ---

  - Type: AFK
  - Blocked by: #3, #4
  - User stories: 21
  - Deterministic post-Reasoner validation: every section ID in cited_sections
  and every policy_basis entry must appear in the chunk IDs returned by the
  Policy Retriever for this request. Hallucinated citation → escalate. Unit
  tests: present → passes; absent → escalates.

  ---
  6. Mock Tool Registry + Tool Executor
  - Type: AFK
  - Blocked by: #2, #5
  - User stories: 1, 3, 4, 5, 6, 7

  query_hr_database, escalate_to_human). Tool Executor: re-runs Trust Gate check
   per tool call, validates Citation Grounding, dispatches to mock tool, passes
  raw output to Output Filter before anything else sees it. Registry description
   included in Reasoner system prompt.

  ---
  7. Output Filter + PII stripping + trace sanitization
  - Type: AFK
  - Blocked by: #6
  - User stories: 11, 22
  - Fixed tool_name → fields_to_strip map covering all 5 tools. Strips PII and

  Unit tests: PII fields stripped; non-PII fields preserved; trace excludes
  sensitive data.

  ---
  8. Full pipeline wiring + CLI runner + Pipeline Trace
  - Type: AFK
  - Blocked by: #2–7

  tokens/cost/retries; tool spans add raw + filtered result). Structured JSON
  log written at request completion. CLI entry point for direct invocation.

  10. Golden test set + CI regression suite
